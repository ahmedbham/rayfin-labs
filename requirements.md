## Goals
- hands-on labs for building `Fabric Apps` using `Rayfin CLI` with the help of `Github Copilot`.
- three hands-on labs covering ease-of-development and advanced capabilities of `Fabric Apps`.
  - Lab 1: Building a basic `Fabric App` using `Rayfin CLI template`.
  - Lab 2: Building a two-tier `Fabric App` where data is stored in a SQL database in Fabric.
  - Lab 3: Building `Fabric App` as an interactive dashboard for Power BI semantic model.

## Instructions
- Initial users of this repo are Microsoft employees with access to a Fabric environment and trial capacity in Microsoft Fabric tenant.
- lab instructions should be generated as Github Pages using a Jekyll-based framework common in Microsoft documentation.
- include comprehensive pre-requisite section.
- Lab 1: guide users to build a basic `Fabric App` by simplifying instructions from: https://github.com/microsoft/awesome-rayfin/tree/main/templates/todo-local-experimental
- Lab 2: guide users to use GitHub Copilot in `plan` mode to execute the prompt in LAB_2_PROMPT.md to generate a plan for the implementation of the functional requirements documented in the LAB_2_FUNCTIONAL_REQUIREMENTS.md file. Then, guide users to use GitHub Copilot in `code` mode to implement the plan.
- Lab 3: guide users to use GitHub Copilot in `plan` mode to execute the prompt in LAB_3_PROMPT.md to generate a plan. Then, guide users to use GitHub Copilot in `code` mode to implement the plan.
