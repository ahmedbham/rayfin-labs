# Labs

Complete the labs in order if Rayfin is new to you. Each lab uses a separate application folder and ends with a deployed Fabric App.

| Lab | Estimated time | Outcome |
|:----|:---------------|:--------|
| [Lab 1: Build a Todo app]({% link labs/lab-1-todo.md %}) | 45-60 minutes | A working CRUD app locally and in Fabric. |
| [Lab 2: Build a field technician app]({% link labs/lab-2-field-technician.md %}) | 90-150 minutes | A role-aware operational app planned and implemented with Copilot. |
| [Lab 3: Build an interactive dashboard]({% link labs/lab-3-dashboard.md %}) | 90-120 minutes | A cross-filterable analytics app over a Power BI semantic model. |

All times exclude prerequisite installation and tenant administration.
